# Internationalization (i18n)

Client-side UI locales for the static SPA (GitHub Pages + `basePath` `/E2`).  
**No URL path prefixes** (`/de/…`) — language is chosen via preference + optional query param.

## Locales

| Code | Language | Role |
|------|----------|------|
| `de` | Deutsch | Default / source of truth for message keys |
| `en` | English | Full mirror of `de` |

## Resolution order

1. `?lang=de` / `?lang=en` (applied once, then stripped from the URL)
2. `localStorage` key `e2.locale`
3. `navigator.languages`
4. Default: `de`

## Usage in components

```tsx
import { useT, useI18n, LanguageSwitcher } from "@/i18n";

function Example() {
  const t = useT();
  const { locale, bcp47, setLocale } = useI18n();
  return (
    <>
      <p>{t("common.save")}</p>
      <p>{t("backup.automaticMinutes", { n: 15 })}</p>
      <time dateTime="…">{new Date().toLocaleString(bcp47)}</time>
      <LanguageSwitcher />
    </>
  );
}
```

Outside React (alerts, `document.title`):

```ts
import { translate, readStoredLocale, DEFAULT_LOCALE } from "@/i18n";

const locale = readStoredLocale() ?? DEFAULT_LOCALE;
alert(translate(locale, "common.loading"));
```

## Adding strings

1. Add the key under the right namespace in [`src/i18n/messages/de.ts`](../src/i18n/messages/de.ts).
2. Mirror it in [`src/i18n/messages/en.ts`](../src/i18n/messages/en.ts) (`satisfies MessageTree` enforces the shape).
3. Use `t("namespace.key")` — TypeScript only accepts existing paths.
4. Run `npm run test:run -- src/i18n/i18n.test.ts` (catalogs must stay in sync).

Placeholders use `{name}` syntax: `t("app.documentTitleWithFile", { file: name })`.

## Layout

- [`AppProviders`](../src/components/app-providers.tsx) wraps the app with `<I18nProvider>`.
- `<html lang>` updates on the client when the locale changes.
- Static `metadata` in `layout.tsx` stays German for now (no locale routing on Pages).
